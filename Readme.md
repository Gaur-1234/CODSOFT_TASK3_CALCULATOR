# 🧮 CalcX — Modern Calculator

A polished, responsive calculator web application built with **HTML5, CSS3, and Vanilla JavaScript** as part of the **CodSoft Web Development Internship — Task 3**.

CalcX combines a modern dark interface with practical calculator functionality, keyboard controls, and persistent calculation history.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Percentage calculation
- Positive/negative sign toggle
- Decimal number support
- Backspace and clear controls
- Full keyboard support
- Calculation history with up to 10 recent calculations
- History persistence with browser localStorage
- Divide-by-zero error handling
- Responsive desktop, tablet, and mobile layout
- Smooth hover and button interactions
- Modern glass-style dark UI

## 🛠️ Tech Stack

- **HTML5** — structure and semantic markup
- **CSS3** — CSS Grid, Flexbox, gradients, responsive design, and UI styling
- **JavaScript (ES6+)** — calculator logic, DOM events, keyboard controls, and localStorage
